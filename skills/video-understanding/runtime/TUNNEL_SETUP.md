# Secure MCP Tunnel setup (Windows)

This Runtime listens locally on:

`http://127.0.0.1:8765/mcp`

ChatGPT cannot connect to localhost directly. The preferred private connection is OpenAI Secure MCP Tunnel.

Official documentation:
https://developers.openai.com/api/docs/guides/secure-mcp-tunnels

## 1. Start the local Runtime

Run:

`scripts\run_windows.ps1`

Keep that PowerShell window open.

Optional local MCP check in another terminal:

`.venv\Scripts\python.exe scripts\mcp_smoke.py`

The smoke test should list five tools.

## 2. Create an OpenAI-hosted tunnel

Open Platform tunnel settings and create/manage a tunnel.

You need:
- a `tunnel_id`;
- Tunnels Read + Use permissions for running/using it;
- Tunnels Manage as well if you create/edit it;
- a runtime API key for `tunnel-client`.

The Runtime itself does not call an OpenAI model API. The key here authenticates `tunnel-client` to the tunnel control plane.

## 3. Get tunnel-client

Use the download link shown in Platform tunnel settings, or the latest public `openai/tunnel-client` release.

Do not hard-code an old release URL.

## 4. Configure the local MCP target

Use the quickstart command generated by your tunnel settings.

For this project, the private MCP target is:

`http://127.0.0.1:8765/mcp`

The official tunnel documentation supports HTTP MCP targets using `--mcp-server-url`.

Set `CONTROL_PLANE_API_KEY` only in your local environment; do not paste it into chat or commit it to GitHub.

## 5. Validate

Run the tunnel client's doctor command for the profile with `--explain`.

Only continue when the tunnel reports healthy/ready and the local MCP server is reachable.

## 6. Connect it in ChatGPT

In ChatGPT developer-mode app creation:

1. Choose Tunnel as the connection type.
2. Select the tunnel (or use its tunnel id if the UI allows).
3. Scan tools.
4. Verify these five tools appear:
   - start_video_analysis
   - wait_video_analysis
   - get_video_manifest
   - get_video_transcript
   - inspect_video_window
5. Keep the app read/fetch only.

## 7. Expected chat experience

Once the Video Understanding app is selected for a message, a bare Bilibili or YouTube URL is enough.

Internally ChatGPT should:
- start the job;
- wait without asking you for the job id;
- load transcript windows;
- inspect overview frames;
- rewatch important ranges densely;
- return the final Chinese analysis.

## Product limitation

Current ChatGPT custom-app selection is message-scoped. A normal unrelated chat is not guaranteed to invoke this custom app merely because a URL was pasted. The reliable target is: select/mention the Video Understanding app for that message, then only paste the URL as the message body.

If a future ChatGPT product surface allows an app/agent to stay permanently bound to a conversation, this limitation can be relaxed without changing the Runtime.
