## Important runtime boundary
A rule file cannot execute before the host/client loads it. Therefore true “always on even when the user never mentions No-Rush” requires the host/router to preload No-Rush before normal Skill discovery. GitHub upload alone cannot force an unrelated ChatGPT/client runtime to read the file.

This means:
- **Fixed in this repository:** activation contract, Question Scan behavior, conflict cleanup, test matrix, checker, documentation.
- **Requires host integration:** actual automatic preload in a specific ChatGPT/Agent/Work/Codex/custom runtime.
