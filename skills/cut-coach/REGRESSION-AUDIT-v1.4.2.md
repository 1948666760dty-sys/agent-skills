# duty-NRV / Cut Coach v1.4.2 — 中文展示回归

日期：2026-09-22

## 目标

保证窄屏默认输出对用户完全可读，不再依赖营养英文缩写。

## 强制规则

- 热量写“热量”
- protein 写“蛋白质”，不得在进度条中缩写为“蛋白”
- carbohydrate 写“碳水化合物”
- fat 写“脂肪”
- fiber 写“膳食纤维”
- 默认用户可见输出禁止 P / C / F / fiber
- kcal、g 作为计量单位可以保留
- A～E 可信度等级中的字母不属于营养缩写，可以保留

## 回归

1. “今日” → 总计使用完整中文名称。
2. “吃了这个” → 本餐核心 5 项使用完整中文名称。
3. 个人 NRV 进度条 → “蛋白质”，不得写“蛋白”。
4. 个人 NRV 进度条 → “碳水化合物”，不得写 C。
5. 个人 NRV 进度条 → “脂肪”，不得写 F。
6. 总计行不得写 P≈130g / C≈200g / F≈48g。
7. 总计行可写：热量≈1800 kcal｜蛋白质≈130 g｜碳水化合物≈200 g｜脂肪≈48 g｜膳食纤维≈14 g。
8. 用户明确要求英文缩写时，才允许临时使用。
9. “蛋白粉”是食品名称，不强行改成“蛋白质粉”。
10. “高蛋白质来源”作为建议文案可使用。

## 结论

静态中文展示检查通过；继续继承 v1.4.0 与 v1.4.1 的所有回归场景。
